🔐 Password Strength Checker using Python

📌 About the Project
Password Strength Checker is a beginner-friendly cybersecurity project developed using Python. It checks password strength against several security criteria.

🚀 Features
- Checks password length.
- Detects uppercase letters.
- Detects lowercase letters.
- Checks numeric characters.
- Identifies special characters.
- Classifies passwords as Weak, Medium, or Strong.

🛠️ Technologies Used
- Python 3
- String Module

▶️ How to Run
1. Clone this repository.
2. Open the project folder.
3. Run the following command:

python password_checker.py

🎯 Learning Outcomes
- Python functions
- Conditional statements
- String methods
- Basic cybersecurity concepts
- Password security fundamentals
